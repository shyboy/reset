# 世界与分集

全系列 12 集发生在一座叫风坡镇的海边小城：前 11 集各占地图上的一个地点、一种价值、一种主题色，第 12 集抵达地图中心。

## 小城：风坡镇

风坡镇（工作名）是一座依山面海的小城，到处是台阶和坡道，海风大、常下雨。风和雨是团团最怕的东西，所以这座城本身就是它每天要面对的小小考验。

- **地形**：从海边一路爬到坡顶，分三层：海边是码头、集市和灯塔，半坡是住家和小店，坡顶是老街、学校和旧楼。
- **气候**：海风从下往上吹，越靠海越大；雨说来就来。很多集的物理障碍都来自这两样。
- **生活气质**：节奏慢，人和人之间有点距离，很多心意都停在“想说没说”。这正是没寄出的信会这么多的原因。
- **美术方向**：低饱和的米白、灰蓝和暖灰为底，线条克制、大面积留白。中式的生活气息，但不刻板，任何地方的观众都能代入。
- **戳戳的家**：半坡街角的一个旧邮筒，旁边就是团团被扔进去的那个垃圾桶。

**两个孩子的痕迹**

这 11 个地点，都是搬走的孩子和好朋友一起去过的地方，所以才会被画进地图。每集会在背景里藏一个两人留下的小痕迹（如第 1 集邮筒底座上两道并排的粉笔身高刻痕、后面集数长椅上并排的石子等）。全片不点破、不给特写，留给反复看的观众。

## 系列节奏

集数的顺序按团团的成长排，而不是按价值的重要性排：它从“被救”走到“主动把自己交出去”。

1. **01–03 相遇与熟悉**：轻快、好笑。团团还处在受惊和观察的阶段，大部分时间躲在包里，偶尔因害怕或意外触发物理线索；戳戳莽撞地横冲直撞，独自承担解谜和送信。观众先爱上这对搭档。
2. **04–07 慢慢靠近**：故事开始有回响。团团第一次比戳戳先看懂一封信并主动提醒它（04），两人第一次一起安静地等待（06）。
3. **08 中段转折**：团团第一次主动面对最怕的风。从这一集起，它不再只是被保护的那一个。
4. **09–11 互相改变**：09 是戳戳的盲点集，团团教会它“不送也是一种尊重”；11 是团团的信任集，它决定让戳戳把自己送出去。
5. **12 结局**：加长特别篇。地图完全展开，团团终于知道自己一直被珍惜。朋友窗台上那封没寄出的信，留作第二季的钩子。

**暗线细节**：收信的那个朋友，会在前面 3–4 集里作为背景路人出现，总是一个人。他也是少数能看见戳戳的小孩之一。观众到结局才认出他。

## 已确认的设定

以下四项已于 2026-11-02 确认。

- **“风坡镇”作为工作名。** 片中不出现文字，名字只用于制作和宣传。
- **地图中心是两个孩子家对门的两扇窗。** 搬走后一扇空了，另一扇里的朋友还在；结局戳戳把团团送到那扇窗前。
- **收信的朋友在 3–4 集里作为背景路人提前出场**，不加任何强调。
- **12 集的价值清单按这一稿推进**，进入单集剧本时再按故事效果替换个别集。
